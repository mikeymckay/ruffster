Website visibility

Checking the local connection…

This add-on runs only in this browser on the child's computer. Using another browser, turning this off, or removing the add-on can leave gaps. The parent report cannot tell why a website is missing.

What is shared

When this is on, the active website's domain name only is sent to the Family Activity agent on this computer.

Page addresses, titles, and contents are not sent. Private-window domains are excluded.

The extension does not keep a website history. It stores your pause setting and a temporary reset flag so estimates do not span a pause, disconnect, or private-window visit.

This controls website observations only. The computer's visible app and network monitoring is separate. Private windows are not inspected for domains. When you return to a regular window, a domain-free marker may end the previous estimate so private time is not attributed to a website. If paused or disconnected, the parent report may have no website observations and cannot show the reason.
