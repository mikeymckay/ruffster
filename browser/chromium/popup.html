Website visibility

Checking the local connection…

This add-on runs only in this browser on the child's computer. Pausing or removing it, or using another browser, can leave gaps.

What is shared

When this is on, the active website's domain name only (for example, wikipedia.org) is sent to Family Activity on this computer.

Page addresses, titles, and contents are not sent. Private-window domains are excluded.

What is saved and why gaps appear

No website history is saved. The add-on remembers your pause choice and when it could not observe the browser, so estimated time does not stretch across a gap.

If a website is missing, the parent report cannot tell whether sharing was paused, disconnected, or simply had nothing to report.

This switch affects website sharing only. The computer's visible app and network monitoring have separate status.
