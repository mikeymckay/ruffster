STEP 2 · DO THIS NOW

Install Ruffster on the child's Mac

On the child's Mac, open the Ruffster install guide and download Ruffster for Mac (Apple silicon). Install it in Applications. Then sign in to the child's account, open Ruffster, choose Set up this Mac together…, and check the account name before continuing.

Back here, choose Show two digits. Enter them on the child's Mac when Ruffster asks to connect. Keep both computers on the same Wi-Fi.

If the digits don't connect, use the connection file instead. It can send reports to you but cannot open them. Your parent PIN stays on this computer.

STEP 3 · AFTER STEP 2

If the computers can't connect directly, save an encrypted report file on the child's Mac and open it here. New reports add observations to the existing report.

4. Review together

This removes the selected computer’s observations from this parent report. It does not delete data on the child computer or in backups you made earlier.

Computer names are encrypted in the parent report and travel with its encrypted backup. Older records without a computer marker stay grouped as older untagged records.

Start with the seven-day summary and the school-hours view. App time is estimated from samples and can include quiet moments; your child can add the context only they know.

Website estimates are optional and experimental. They need a separate add-on on the child's computer, not the parent's. The Mac setup does not connect the add-on to the agent, so installing it alone will not add websites to this report. The add-on only sees supported browsers where it is installed; your child can pause or remove it, or use another browser. It is not needed for the main app; the report still shows app and network summaries without website details.

How website information works

The add-on runs inside supported browsers on the child's computer. It reports domain names only, not full addresses or page contents. Your child can pause or remove it. If a report has no website observations, it cannot tell whether the add-on was paused, disconnected, or simply had nothing to report.

                                                  Ruffster notices when the default router changes. Give a network you recognize a Home, School, or Other label. These are family labels, not location checks.

                                                  Content filtering setup Observed settings

                                                  No system settings observation is in this report.

                                                    Ruffster can show whether it noticed DNS, proxy, or built-in VPN settings. These clues don't tell us whether a content filter is working. Some setups may not appear here, including secure DNS in a browser, an app's own DNS, a school proxy, or a managed VPN.

                                                    • A filter on your home router usually works only while the computer is on home Wi-Fi; by itself, it doesn't follow the computer to school Wi-Fi or a hotspot.
                                                    • A filter app or device profile may work on other networks if the setup supports them and the school allows it. VPN and secure DNS settings can affect which service the computer uses.
                                                    • To check a filter, use the provider's own test at home, at school, and on a hotspot. Ask the school before changing settings on a school-managed computer.

                                                    NextDNS explains router and device setup as one example. Check a service's privacy and retention choices before choosing it. A proxy may be part of normal school setup; if anything is unclear, ask before changing it.
