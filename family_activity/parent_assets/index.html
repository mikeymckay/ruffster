I already set up parent access

Choose the encrypted recovery copy from your previous parent computer, then enter the same six-digit PIN. This lets you open existing reports here. For a recovery copy created with an older version, enter the phrase you used then. Access already set up on this device is never replaced.

2. Set up the child's computer

On the child's computer, open Ruffster and choose Set up this computer for a child. Keep both computers on the same Wi-Fi. Enter the two digits shown here on the child's setup screen. Read the collection details together before installing. Your PIN never goes to the child's computer. You can add more computers later and review each one separately.

If these digits don't work on this Wi-Fi, choose Download the connection file and select it during setup. This file cannot open reports. Keep the recovery copy and PIN on your parent device.

The Mac setup is an experimental preview. Windows setup and dashboard pairing are also experimental and have not been validated on Windows. Neither is ready for family use.

3. Bring back a report

On the child's computer, open the visible Ruffster status menu and choose Share an encrypted report. It will show two digits. Enter them here. Keep both computers on the same Wi-Fi.

New observations are added to the report already saved here. If a report is sent again, exact copies of the same records are ignored; your retention setting still applies. Computers use random encrypted markers. You choose the names shown in this dashboard.

The button becomes available when you have entered two digits.

4. Review together

Computer names are saved encrypted on this parent computer. Older records without a computer marker stay grouped as older untagged records.

Start with the seven-day summary and the school-hours view. These are estimates from samples; they can include idle or locked time and do not prove active use.

Website estimates are optional and experimental. They need a separate add-on on the child's computer, not the parent's. The Mac setup does not connect the add-on to the agent, so installing it alone will not add websites to this report. The add-on only sees supported browsers where it is installed; your child can pause or remove it, or use another browser. It is not needed for the main app, and missing websites do not explain what happened.

How website information works

The add-on runs inside supported browsers on the child's computer. It reports domain names only, not full addresses or page contents. Your child can pause or remove it. If a report has no website observations, it cannot tell whether the add-on was paused, disconnected, or simply had nothing to report.

                                                  Network protection indicators Observed settings

                                                  No system settings observation is in this report.

                                                    These indicators do not confirm that content filtering is active. A DNS resolver can be ordinary, and browser encrypted DNS, an app's own DNS, a school proxy, or a managed VPN may not appear here.

                                                    • A filter set up only on your home router normally applies while the computer uses that router. By itself, it does not follow the computer to school Wi-Fi or a mobile hotspot.
                                                    • A device profile or filtering app may work on other networks if that setup supports them and remains allowed and active. A VPN, browser's secure DNS, or school-managed setting can change which service handles DNS.
                                                    • Check the filter provider's own status or supported test separately on home Wi-Fi, school Wi-Fi, and a hotspot. Ask the school before changing settings on a school-managed computer. This report cannot verify that filtering works.

                                                    For example, NextDNS explains its device and router setup choices. Review any service's privacy and retention terms before choosing it. A proxy can be normal on a school or work device; treat an indicator as a prompt to understand the setup, not as evidence of misconduct.

                                                              Keep your parent report

                                                              This controls how long detailed records stay in the encrypted report on this device. Older events are removed when you import or open a report, and immediately when you shorten this setting. The child's computer has a separate retention setting.

                                                              Download encrypted report backup

                                                              An exported report backup stays encrypted, but it is outside this retention setting and is not removed by the delete button. Store it safely. Deleting this device's report removes its encrypted database and SQLite sidecars but keeps the parent key.

                                                              Designed for openness

                                                              Tell your child what is collected and review settings together. The preview does not collect screenshots, keystrokes, microphone or camera data. It cannot reliably prove location, intentions, or website traffic.
