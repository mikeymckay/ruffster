I already set up parent access

Choose the encrypted recovery copy from your previous parent computer, then enter the same six-digit PIN. This lets you open existing reports here. For a recovery copy created with an older version, enter the phrase you used then. Access already set up on this device is never replaced.

2. Set up a child's computer

On one child's Mac, open Ruffster and choose Set up this Mac together…. Keep both computers on the same Wi-Fi and enter the two digits shown here. Read the collection details together before setting up monitoring. Your PIN stays on the parent computer. Repeat these steps for each child's Mac. When a report arrives, give each computer a name in the dashboard so you can review them separately.

If these digits don't work on this Wi-Fi, choose Download the connection file and select it during setup. This file can send reports to you, but cannot open them. Keep the recovery copy and PIN on your parent computer.

The Mac app is ready for a first family setup, with monitoring status visible on the computer. Windows setup is still being built and checked on Windows.

3. Bring back a report

On the child's computer, open the visible Ruffster status menu and choose Share an encrypted report. It will show two digits. Enter them here. Keep both computers on the same Wi-Fi.

New observations are added to the report already saved here. If a report is sent again, exact copies of the same records are ignored; your retention setting still applies. Computers use random encrypted markers. You choose the names shown in this dashboard.

The button becomes available when you have entered two digits.

4. Review together

This removes the selected computer’s observations from this parent report. It does not delete data on the child computer or in backups you made earlier.

Computer names are encrypted in the parent report and travel with its encrypted backup. Older records without a computer marker stay grouped as older untagged records.

Start with the seven-day summary and the school-hours view. App time is estimated from samples and can include quiet moments; your child can add the context only they know.

Website estimates are optional and experimental. They need a separate add-on on the child's computer, not the parent's. The Mac setup does not connect the add-on to the agent, so installing it alone will not add websites to this report. The add-on only sees supported browsers where it is installed; your child can pause or remove it, or use another browser. It is not needed for the main app; the report still shows app and network summaries without website details.

How website information works

The add-on runs inside supported browsers on the child's computer. It reports domain names only, not full addresses or page contents. Your child can pause or remove it. If a report has no website observations, it cannot tell whether the add-on was paused, disconnected, or simply had nothing to report.

                                                  No system settings observation is in this report.

                                                    These indicators do not confirm that content filtering is active. A DNS resolver can be ordinary, and browser encrypted DNS, an app's own DNS, a school proxy, or a managed VPN may not appear here.

                                                    • A filter set up only on your home router normally applies while the computer uses that router. By itself, it does not follow the computer to school Wi-Fi or a mobile hotspot.
                                                    • A device profile or filtering app may work on other networks if that setup supports them and remains allowed and active. A VPN, browser's secure DNS, or school-managed setting can change which service handles DNS.
                                                    • Check the filter provider's own status or supported test separately on home Wi-Fi, school Wi-Fi, and a hotspot. Ask the school before changing settings on a school-managed computer. This report cannot verify that filtering works.
