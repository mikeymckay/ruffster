Getting started

Start with a clearer view, together.

Ruffster helps families understand computer use and talk about it constructively, especially during school hours. Start the Mac family preview here; the setup is designed for parents and children to do together.

The Mac family preview is ready for you to try together. Ruffster is made for everyday family use at home and during the school day. macOS asks you to confirm before opening because the app has not yet been signed by Apple. Windows is coming next.

For parents

The Mac app keeps an encrypted activity report for the parent and shows a menu-bar status while Ruffster is running. Install it on your Mac first, then set up each child's Mac together. We're refining the steps as families try them. Windows is next.

Get the Mac app. Download the Apple-silicon Mac app from GitHub Releases. On first open, macOS asks you to confirm because this open-source app has not yet been signed by Apple. Follow Apple’s steps to open an app you downloaded, then continue with family setup. You do not need to change your Mac's security settings.

Install it on each Mac

  1. Download the Mac app from GitHub Releases and open the downloaded .dmg file.
  2. Drag Ruffster into the Applications folder shown in the window.
  3. Open Ruffster from Applications. If macOS asks you to confirm the first launch, follow Apple’s linked steps above.
  4. On your Mac, choose Open parent dashboard. Set your parent PIN and save the recovery copy. On each child’s Mac, choose Set up this Mac together… and read the collection choices together.

Once both Macs are set up, connect them and share a report:

  1. Start on the parent computer. Choose six numbers your child does not know. Ruffster uses them to keep the reports for you. Save the recovery copy so you can bring your reports to another parent computer if you need to.
  2. Set up each child's computer together. Read the collection choices together, decide how long to keep detailed records, and check the visible status indicator. To connect the computers, pair each child's Mac with the parent Mac: one shows two digits and the other enters them. Keep both on the same Wi-Fi. Mac may ask to find nearby computers; allow Local Network access so Ruffster can connect the computers. If that Wi-Fi keeps devices separate, save an encrypted report file from the child's status menu and open it in the parent's dashboard.
  3. Review an encrypted report. Open it on the parent's computer. The report gives you a shared starting point for talking about computer use.

About websites: The main app works without a browser add-on. An optional experiment can share domain names from selected browsers on the child's computer. It is not included in the Mac setup, and reports make clear when website details were not observed.

Families set up Ruffster themselves; the school does not install or operate it. macOS comes first, followed by Windows. Linux is for development and testing.

Current preview status

macOS

The Mac family preview includes background monitoring, a visible menu-bar status, parent-encrypted activity, and a local dashboard. Its build and report flow have been checked on an Apple-silicon Mac with made-up activity. The Mac test suite ran 281 tests (273 passed; 8 platform/dependency checks skipped). macOS comes first; we are now checking the first-run screens, VoiceOver, sleep/wake, and report sharing on family Macs.

Windows

A Windows x64 setup and tray companion, parent dashboard launcher, and collection adapters are in development. GitHub Actions builds the package and runs synthetic setup, Task Scheduler restart/removal, and parent-dashboard checks on a Windows runner. Next we’ll review the setup, tray, updates, and report sharing on a family Windows computer.

For contributors

Use a recent Python 3 and a virtual environment. Linux is supported as a convenient development/test host; tests there do not prove macOS or Windows behavior. 

python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m unittest discover -s tests -v
node --check family_activity/parent_assets/app.js

For a Mac bundle, use a Mac with PyInstaller and the project dependencies installed: 

./scripts/build-macos-preview.sh \
  "$(pwd)/.venv/bin/python" \
  "/absolute/path/to/output-directory"

For the Windows preview, build on Windows x64 with Python, PyInstaller, and the .NET 10 LTS SDK. From the repository root, run python -m pip install -e ".[build]" and then ./scripts/build-windows-preview.ps1 -OutputDirectory ./dist/FamilyActivityPreview in PowerShell. The Windows builder also creates a direct-download per-user installer that copies its files and then opens family setup; monitoring still requires family confirmation. Linux cross-compilation checks that executable can be built, but cannot run Windows extraction, setup, or tray behavior.

When family releases are ready

The Mac family preview is available now. We’re using it to refine setup, report sharing, accessibility, and help for parents. The same step-by-step experience will follow on Windows.

Reports show what Ruffster observed. When observations pause, Ruffster marks a gap instead of guessing why. You can see when the report has a complete picture and when it has a break.
