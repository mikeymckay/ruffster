Getting started

Start with a clearer view, together.

Ruffster helps families understand computer use and talk about it constructively, especially during school hours. Start the Mac family setup here; the steps are designed for parents and children to follow together.

Ruffster for Mac is ready for families. This is Ruffster's first Mac family release. Automated and synthetic checks are complete; the first family setup and report exchange are the next hands-on checks. macOS asks you to confirm before opening because the app has not yet been signed by Apple. Windows setup is being prepared for a family-computer try.

For parents

The Mac app keeps an encrypted activity report for the parent and shows a menu-bar status while Ruffster is running. Install it on your Mac first, then set up each child's Mac together. Everyone can see what Ruffster records and when it is running. The dashboard helps you look at the week and talk about it together.

Get the Mac app. Download Ruffster for Mac 0.1.11 (Apple silicon, .dmg). See the release notes, source, and SHA-256 checksum.
Opening Ruffster the first time

If your Mac says it cannot check Ruffster or verify its developer, choose Done. In System Settings → Privacy & Security, scroll to Security and choose Open Anyway for Ruffster. Open Ruffster again and choose Open. This approves Ruffster as an individual app; your Mac’s general app protections stay on. See Apple’s current instructions.

If macOS says Ruffster will damage your computer or is damaged, stop and contact the Ruffster project instead of opening it.

Install it on each Mac

  1. Download Ruffster from the link above and open the downloaded .dmg file.
  2. Drag Ruffster into the Applications folder shown in the window.
  3. Open Ruffster from Applications. If macOS asks you to confirm the first launch, use the Opening Ruffster the first time steps above.
  4. On your Mac, choose Open parent dashboard. Set your parent PIN and save the recovery copy. On each child’s Mac, choose Set up this Mac together… and read the collection choices together.

After setup, Ruffster starts automatically whenever the child signs in to that Mac. macOS restarts it if the background agent stops unexpectedly; the menu-bar paw shows when fresh samples are arriving or monitoring is paused.

Once your parent Mac and both child Macs are set up, connect them one child Mac at a time and share each report:

  1. Start on the parent computer. Choose six numbers your child does not know. Ruffster uses them to keep the reports for you. Save the recovery copy so you can bring your reports to another parent computer if you need to.
  2. Set up each child's Mac together, one at a time. Read the collection choices together, decide how long to keep detailed records, and check the visible status indicator. Pair each Mac with the parent Mac: one shows two digits and the other enters them. Keep the parent Mac and the child Mac you are setting up on the same Wi-Fi. Mac may ask to find nearby computers; allow Local Network access so Ruffster can connect the computers. If the digits cannot connect, download the connection file from the parent dashboard, move it to the child's Mac, and choose Choose connection file… during setup. This is different from the recovery copy: the connection file lets the child send reports to you, while the recovery copy stays with the parent. After setup, the child can share an encrypted report over Wi-Fi or save an encrypted report file from the child's status menu and open it in the parent's dashboard. After each first report arrives, give that computer a name in the dashboard so you can tell the reports apart.
  3. Review an encrypted report. Open it on the parent's computer. The report gives you a shared starting point for talking about computer use.

About websites: The main app works without a browser add-on. An optional experiment can share domain names from selected browsers on the child's computer. It is not included in the Mac setup, and reports make clear when website details were not observed.

Families set up Ruffster themselves; the school does not install or operate it. macOS comes first, followed by Windows. Linux is for development and testing.

Current Mac app status

macOS

Mac 0.1.11 includes background monitoring, a visible menu-bar status, parent-encrypted activity, and a local dashboard. Its setup guide explains how to add each child's Mac, name reports separately, and know when monitoring starts. Automated checks and synthetic report flows passed; the first family setup and report exchange are the next hands-on checks. VoiceOver and physical sleep/wake still need review.

Windows

A per-user setup, visible tray indicator, parent dashboard launcher, and update flow are implemented. GitHub Actions builds the package and all four Windows test groups passed. Next we’ll review setup, tray, updates, and report sharing on a family Windows computer.

For contributors

Use a recent Python 3 and a virtual environment. Linux is supported as a convenient development/test host; tests there do not prove macOS or Windows behavior. 

python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m unittest discover -s tests -v
node --check family_activity/parent_assets/app.js

For a Mac bundle, use a Mac with PyInstaller and the project dependencies installed: 

./scripts/build-macos-preview.sh \
  "$(pwd)/.venv/bin/python" \
  "/absolute/path/to/output-directory"

For the Windows preview, build on Windows x64 with Python, PyInstaller, and the .NET 10 LTS SDK. From the repository root, run python -m pip install -e ".[build]" and then ./scripts/build-windows-preview.ps1 -OutputDirectory ./dist/FamilyActivityPreview in PowerShell. The Windows builder also creates a direct-download per-user installer that copies its files and then opens family setup; monitoring still requires family confirmation. Linux cross-compilation checks that executable can be built, but cannot run Windows extraction, setup, or tray behavior.

Contributing to Ruffster

Ruffster for Mac is available for ongoing family use. We’re using first family sessions to make setup, report sharing, and parent help even clearer. The same step-by-step experience will follow on Windows.

Reports show what Ruffster observed. When observations pause, Ruffster marks a gap instead of guessing why. You can see when the report has a complete picture and when it has a break.
