A simple family setup

Set up Ruffster, one step at a time.

Keep the parent dashboard on your computer. Install one app on the Mac Ruffster will monitor. Set it up together, then bring reports back to review.

What to install on the child's MacDownload Ruffster for Mac 0.1.26 · Apple silicon. See release notes and checksum. This is the Ruffster app for your child's Mac. It works on Apple-silicon Macs running macOS 12 Monterey or newer. You do not need a browser extension.

Start here

  1. Open the parent dashboard.

    On the parent's computer, open Ruffster. Choose six numbers the child does not know, then save the recovery copy somewhere the child cannot access. That computer keeps the parent access and reports.

  2. Install Ruffster on the child's Mac.

    Open the downloaded Ruffster-Mac-Family-App-Apple-Silicon.dmg. Drag Ruffster to Applications. Sign in to the child's Mac account, open Ruffster, and choose Set up this Mac together…. Check the account name shown before continuing. Ruffster monitors only the account used for setup.

    Read the collection choices together. The menu-bar paw shows whether monitoring is on. Ruffster records only while the Mac is awake and the child is signed in; normal sleep is fine, and the report marks time it could not observe.

  3. Connect the computers and bring back a report.

    Keep both computers on the same Wi-Fi. In the parent dashboard choose Show two digits; enter them in Ruffster on the child's Mac. If they cannot connect, use the connection file instead. Later, choose Share an encrypted report from the menu-bar paw and enter its two digits in the parent dashboard. You can also save a report file and open it on the parent computer.

Using a Linux laptop for the parent dashboard

A one-click Linux parent app is not available yet. For now, the parent dashboard can run from the Ruffster project on your Linux laptop. Open Terminal and run:

git clone https://github.com/mikeymckay/ruffster.git
cd ruffster
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m family_activity parent

Ruffster opens the parent dashboard in your browser and keeps its files in your Linux account. Leave the terminal and dashboard open while connecting the Mac or receiving a report. The dashboard is local to this laptop; Linux is not monitoring the child's activity.

If macOS asks before opening

Ruffster is an open-source app that is not signed by Apple. If macOS says it cannot verify the developer, choose Done. Open System Settings → Privacy & Security, scroll to Security, and choose Open Anyway for Ruffster. Open it again and choose Open. This approves Ruffster only; leave the Mac's general protections on. Follow Apple's instructions.

If macOS says the app will damage the computer or is damaged, stop and contact the Ruffster project.

That’s all you need to start. The main Ruffster app does not block websites or apps. It does not take screenshots, record typing or messages, or use the microphone or camera. It helps your family look at observations together; it cannot explain why an observation is missing.
