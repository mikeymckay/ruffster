A clearer picture, with honest limits

A helpful view, with room for context.

Computer activity can be hard to interpret. Ruffster makes the observations easy to review and the estimates easy to recognize.

What Ruffster can observe

  • Which application was in the foreground at sample times.
  • Total network bytes reported by the computer’s interfaces.
  • On macOS, an optional experimental summary of bytes associated with processes.
  • Monitoring sessions and gaps between observations.
  • The main app needs no browser add-on. An optional experimental add-on would run in selected browsers on the child’s computer—not the parent’s—and can be turned off or bypassed. Internet traffic totals alone cannot show which sites were visited; missing website names do not explain why they are missing. It is not part of supported setup.

What to read with context

  • Time between samples is an estimate and can include idle time.
  • Interface totals do not identify the websites or apps that used them.
  • Process totals may list helper services, and quick connections can be missed.
  • Why an observation paused or a network changed.
  • Whether a content filter is working; network settings need context.
How the family flow is designed

Three steps. No school setup.

A parent prepares the key, the child sees the setup and indicator, and the parent reviews an encrypted report locally.

01

Set up together

Read the collection choices together, choose how long to keep details, and make sure Ruffster’s visible status is easy to find.

02

Reports stay with the parent

The child computer encrypts observations for the parent. The parent keeps the PIN and recovery copy on their own computer. No cloud account is needed.

03

Review what is known

See estimates, network totals, and missing intervals with uncertainty stated. Use the report as a starting point for a conversation.
