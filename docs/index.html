A family-first activity summary

Make computer use easier to talk about.

Family Activity is an early, open-source prototype for parents and children to review computer use together—with visible monitoring, local reports, and clear limits on what the data can tell you.

A clearer picture, with honest limits

Observations need context.

The goal is to help a family ask better questions. A measurement is only useful when its limits are visible too.

What the prototype can measure

  • Which application was in the foreground at sample times.
  • Total network bytes reported by the computer’s interfaces.
  • Monitoring sessions and gaps between observations.
  • The main app needs no browser add-on. An optional experimental add-on would run in selected browsers on the child’s computer—not the parent’s—and can be turned off or bypassed. Internet traffic totals alone cannot show which sites were visited; missing website names do not explain why they are missing. It is not part of supported setup.

What it cannot conclude

  • Whether a child was actively using an app between samples.
  • Which website or app caused interface-level network traffic.
  • Why monitoring stopped or a network changed.
  • Whether a filter is working, or whether activity was appropriate.
How the family flow is designed

Three steps. No school setup.

A parent prepares the key, the child sees the setup and indicator, and the parent reviews an encrypted report locally.

01

Set up together

Explain the monitoring before installation. Choose a short retention period and make sure the visible status indicator is present.

Preview setup guide →
02

Keep details protected

The child computer encrypts observations to a public key. The parent keeps the matching private key and six-digit PIN; no cloud account is required.

03

Review what is known

See estimates, network totals, and missing intervals with uncertainty stated. Use the report as a starting point for a conversation.
